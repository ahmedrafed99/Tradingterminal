Z-Index Stack
Layers from Z.* in constants/layout.ts. Never use a raw number. Intentionally spaced to allow future insertions.
Z.HEADER10Sticky table headers, loading overlays, labels
Z.OVERLAY20Overlay containers (chart overlay wrapper)
Z.TOOLBAR30Drawing toolbar, quick-order box, scroll buttons
Z.TOOLBAR_EDIT40Drawing edit toolbar (must sit above Z.TOOLBAR)
Z.DROPDOWN50All dropdowns, popovers, selects, color pickers
Z.MODAL60Full-screen modal overlays (above dropdowns)
Z.TOAST100Toast notifications, top-level color popovers
Motion
Three transition speeds from tokens.css. Every interactive state change must be animated — never use instant color changes.
Transition Durations — hover to compare
--transition-fast · 0.15s
Most interactions
--transition-normal · 0.2s
Icon opacity, scroll button
--transition-slow · 0.25s
Modal entrance, crosshair
Keyframe Animations — click to replay
toolbar-in
0.15s ease-out · slides down from -6px
toolbar-left
0.15s ease-out · slides in from left
dropdown-in
0.15s ease-out · fade + scale(0.97→1)
modal-in
0.25s cubic-bezier(0.16,1,0.3,1)
toast-in
0.2s ease-out · slide from right
recording-pulse
1.2s ease-in-out infinite
